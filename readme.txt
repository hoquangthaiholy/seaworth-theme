== Description ==

Seaworth is a high-end, luxury corporate Full Site Editing (FSE) block theme designed for Seaworth Holding (THE POETIC OCEANIC CLASS). Built upon WordPress theme.json version 3 standard, featuring fluid typography, luxury oceanic color palette, and bespoke block styling.

== Features ==
- Theme.json Version 3 standard
- Full Fluid Typography with min/max clamp scaling across 375px - 1440px viewports
- 11-step Curated Oceanic Color Palette
- Bespoke typography pairings: Cormorant Garamond, Noto Serif TC, and Montserrat
- Production-ready block template hierarchy: Index, Page, Single, Archive, 404, Header, and Footer
